2.2 · Guía paso a paso

Cómo resolver un control

Identifica el riesgo: comienza preguntando qué quieres comprobar: microorganismos, contaminantes químicos, alérgenos, composición nutricional, autenticidad u OGM.
Selecciona el método: relaciona el riesgo con una técnica apropiada. La aplicación muestra una orientación, no sustituye el método validado del laboratorio.
Registra: anota la muestra, fecha, método, equipos/instrumentos y resultado. La trazabilidad facilita revisar el control después.
Decide: usa estados como Pendiente, Conforme o No conforme de acuerdo con la evidencia disponible y los criterios definidos para el alimento.
